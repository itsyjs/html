# `@itsy/html/a11y` has moved

The accessibility rules now live inside [`check()`](/api/check#accessibility) and run by default,
so there is nothing to import. The entry point is gone.

| before                                            | now                                                |
| ------------------------------------------------- | -------------------------------------------------- |
| `check(page)`, the markup check alone             | `check(page, { a11y: false })`                     |
| `check(page, { a11y })`                           | `check(page)`                                      |
| `check(page, { a11y: without('img-alt') })`       | `check(page, { a11y: { without: ['img-alt'] } })`  |
| `import type { A11yRule } from '@itsy/html/a11y'` | `import type { A11yRule } from '@itsy/html/check'` |

With the rules on, the list `check()` returns holds a `Finding` for each rule that fires, next to
the `Problem`s. A finding has a `rule` name instead of a `code`, so code that reads `p.code` should
tell the two apart with `'rule' in p` — see [`Finding`](/api/check#finding).
